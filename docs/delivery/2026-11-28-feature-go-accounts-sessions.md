# 账号与会话功能交付说明

## 功能范围

控制台提供独立的“账号与会话”页面，用于修改本人密码、查看和注销本人设备会话。会话信息包含设备 IP、浏览器标识、登录时间、最后活跃时间、过期时间及当前设备标识。

管理员可创建控制台账号、设置管理员或只读运维角色、启停账号和重置密码。上述操作均需输入操作人的当前密码。最后一个启用的管理员账号受保护，当前登录账号不能停用自身。角色变更后目标账号的全部会话失效；停用账号后，其历史会话在重新启用时仍然失效。

只读运维账号可以查看仪表盘、发信记录、客户端概况、定时任务和审计日志，并管理本人密码与会话。账号管理、全局设置、迁移、密钥查看、测试发信、任务执行和业务配置修改仅对管理员开放。

## 会话机制

登录凭证采用随机令牌，服务端仅持久化摘要。会话最长有效时间为 24 小时，连续空闲 60 分钟后失效。最后活跃时间按分钟更新。过期会话不作为活跃会话展示，并在后续登录时清理。

修改本人密码保留当前会话标识和原过期时间，同时轮换当前凭证并注销其他会话。重置本人密码同样保留当前设备；重置其他账号密码会注销目标账号全部会话。退出登录和手动注销在数据库中撤销凭证，复制的旧凭证无法继续访问。

账号变更、凭证撤销与对应审计记录在同一事务内提交。任一环节失败时，整个操作回滚。并发操作至少保留一个启用的管理员账号。

## 接口说明

管理接口前缀为 `/admin/api/v1`，登录使用 HttpOnly Cookie，也支持 Bearer 凭证。错误响应包含 `error.code` 和 `error.message`。

| 方法与路径 | 用途 | 请求字段与权限 |
| --- | --- | --- |
| GET /auth/sessions | 查看本人活跃会话 | 返回 items；所有登录账号可用 |
| DELETE /auth/sessions/:id | 注销指定会话 | 本人会话可注销；管理员可注销其他账号会话 |
| PUT /auth/password | 修改本人密码 | old_password、new_password；启动救援状态允许直接设置新密码 |
| GET /admins | 查看账号列表 | 返回 items；仅管理员 |
| POST /admins | 创建账号 | username、password、role、current_password；仅管理员 |
| PUT /admins/:id | 更新账号 | role、is_active、password 中至少一项，以及 current_password；仅管理员 |

用户名为 3–64 字节，密码为 8–72 字节。角色取值为 `admin` 或 `viewer`。无效或撤销凭证返回 401，无操作权限返回 403，目标不存在返回 404，用户名冲突或最后一个管理员保护返回 409，参数或密码复核失败返回 400。

## 数据与升级

启动时自动补齐会话存储与账号角色。已有账号保持管理员身份，原账号密码及业务数据保持原值。升级后已有登录需要重新登录一次。

环境迁移包包含账号角色，未携带角色的旧包按管理员身份导入。覆盖账号时同时撤销该账号会话。导入结果必须包含至少一个启用的管理员，否则整个导入事务回滚。会话凭证不随迁移包导出或恢复。

本功能沿用现有依赖，无需安装新的服务、库或环境变量。可在同一维护窗口内更新程序并启动，数据库结构在启动阶段处理。

## 验证范围

验证覆盖多设备独立凭证、当前设备标识、会话注销、密码轮换、角色变更、停用后重新启用、只读接口权限、密码字节数边界、并发管理员保护、审计失败回滚、绝对过期与空闲过期、旧数据库升级、旧迁移包兼容和角色跨实例恢复。

## 验证结果

全量 Go 测试与竞态检测、`go vet ./...`、前端 TypeScript 检查和 Vite 构建均通过。程序以 `v1.2.0` 版本参数构建成功。

隔离实例的浏览器验收通过，覆盖初始化管理员、创建只读账号、注销当前会话后返回登录页、只读账号登录和接口权限，以及中英文、暗色桌面和手机宽度布局。只读账号直接访问受限页面时显示本人账号与会话页面。

迁移覆盖测试确认覆盖账号会撤销原会话；导入试图降权最后一个管理员时，账号角色、密码及原会话均保持原值。
